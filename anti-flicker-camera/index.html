使用注意① 请用 Chrome / Edge / Safari 的 HTTPS 网页或 localhost 打开；直接使用 HTTP 局域网地址时浏览器通常无法调用摄像头。
② 电视或投影画面上的横向条纹主要与 LED 屏幕刷新、PWM 调光和相机滚动快门有关。调节 fps 不等同于调节快门曝光时间，因此不能保证完全消除。对于不支持浏览器曝光控制的手机，请使用系统相机的“专业模式”，尝试 1/50 或 1/100 秒（50Hz）以及 1/60 或 1/120 秒（60Hz），并尽量关闭屏幕 PWM 调光。
③ 如条纹明显，尝试降低/提高屏幕亮度、避免电子快门、打开相机的防频闪选项。自动评分可能受到屏幕内容中真实水平线条的干扰。
